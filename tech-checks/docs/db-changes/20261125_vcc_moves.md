# 2026-11-25 — Moved in VCC (Tech Check functions)

Project: Tech Check `goqrnolcvqnirjmzaeyk`
Source: `tech-checks/database-maintenance/cos-vcc-moves-v1.sql` (applied by hand 2026-11-25)

James asked for it ("Build move in VCC") after Spotter 265 / SolarSpotter 253:
VCC was right, but COS kept a camera under its old unit, never added a new one
and kept a removed NVR. The VCC sync deliberately never moves, adds or turns
off a camera record by itself, so this lists the differences and lets the Owner
or approved IT apply them one at a time from the punch list.

- `app_private.cos_vcc_unit_of(name)` — family and number from a name
  (Spotter, Solar Spotter and SS Hybrid count as one family).
- `app_private.cos_vcc_moves_compute()` — the list, only from a whole-account
  VCC sync under 2 hours old: **moved** (VCC names the camera for another unit
  number), **new** (VCC camera COS never matched), **gone** (not listed by VCC
  for 12 hours). A button only when exactly one COS unit fits.
- `public.cos_vcc_moves_state_v1()` and `public.cos_vcc_move_apply_v1(key, name)`
  — Owner or approved IT (`cos_verified_fleet_actor`). Apply works the list out
  again and refuses anything no longer listed or not safe.
- `app_private.cos_vcc_move_log` — every apply, with the row before and after,
  who and when.

No `camera_inventory_audit` row is written, so the sweep allow-list is untouched.
Checked by tests that rolled themselves back: replaying the 265/253 case listed
exactly the move and the new camera and applied both to match the hand fix;
"gone" turns a record off; the unnamed "Shop" camera is refused. Live list at
apply time: SolarSpotter 029_4 (gone since Nov 24) and "Shop" (no unit).

The Operations side ships as recorded patch `cos-unit-camera-status/vcc-moves-v20`
(from live v20 `a9cc477f`), rollback `rollback-to-v20-entry`.

Rollback:

```sql
drop function if exists public.cos_vcc_move_apply_v1(text, text);
drop function if exists public.cos_vcc_moves_state_v1();
drop function if exists app_private.cos_vcc_moves_compute();
drop function if exists app_private.cos_vcc_unit_of(text);
```

Undo one applied change from its log row: restore `before_row` for a move or
turn-off, or delete the inserted row (`after_row->>'id'`) for an add.
