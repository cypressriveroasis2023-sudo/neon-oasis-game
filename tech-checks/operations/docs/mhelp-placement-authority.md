# mHelp placement authority

The latest accepted, complete mHelp API snapshot or approved uploaded export is
the placement source for each exact Product ID. Daily mHelp assignment edits
therefore direct the COS Field/Shop census. Connectivity, missing camera links,
missing GPS and identity review do not remove a Product ID from that census.

Shop is established by the reviewed company customer IDs carried in the source
receipt. ROOT is a Shop presentation label, not a license to classify arbitrary
customer names containing “camera” or “shop.” The API source validates portal,
customer identity, complete membership and two consistent equipment reads.

The existing importer and scheduler remain in use. Incomplete or failed reads
cannot replace the accepted snapshot; the UI retains its original source time,
last successful sync and failure indication. A newly absent Product ID is kept
as historical missing evidence; it is not deleted. Source snapshots and run
receipts retain dated movement evidence without rewriting native history.

The 2027 tracker is a separate reconciliation destination. Existing exact
Product-ID bindings and matching current rows permit its guarded publisher to
update placement/customer/site cells. Missing bindings, shifted rows, manual
edits, stale evidence and identity/installation holds remain explicit review
items. They do not reverse accepted mHelp placement or hide Field inventory.
The saved import's tracker census is historical and is not represented as a
fresh Google Sheets read.

Online/offline describes available unit or recorder connectivity. Camera
channels and live video require their own evidence. Unavailable evidence stays
unverified and cannot be called a confirmed customer-site outage.

Regression coverage exercises Shop → Field → Shop through the API source,
read-only COS projection, Field census, guarded Sheet publishing planner and
immutable database receipts. Browser tests exercise the census with offline
recorder evidence and with failed health, without GPS or production movements.
IP/SIM, camera identities, manual holds, permissions and schedules are unchanged.
