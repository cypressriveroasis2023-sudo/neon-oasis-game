# Shared IT queue

When scheduling an IT visit, choose **IT shared queue** or a named technician.
Saving the schedule does not send the job to the queue. Use **Send to IT queue**
when it is ready for an authorized IT technician to take ownership.

Technicians can see shared work on their landing dashboard and Operations
assignments. **Take job** records the first successful claim and shows the
claimant to the other technicians. Refresh if the job was taken by someone else
or the result could not be confirmed.

Jobs can be claimed before unit and workflow setup is finished. Setup, dispatch,
and starting work remain separate steps. Existing named assignments are kept.
