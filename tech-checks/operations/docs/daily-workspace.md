# Daily workspace simplification

Overview and Shop / ROOT read the same reviewed mHelp Product-ID receipt and manual-Shop projection as Fleet. Native registry and historical tracker subsets no longer appear as competing headline inventory totals. Product IDs remain distinct; no equipment associations are inferred from labels. Invalid receipts produce unavailable data, not zeros. A failed refresh retains the previous reviewed inventory with an explicit message. Session invalidation clears it.

Shop shows the reviewed records, searched and paginated. A unique current Product-ID/native association may open the common unit card. Registry readiness and older tracker records are optional details, explicitly a subset; Shop placement never establishes deployment readiness.

Overview supplies work shortcuts and shared inventory instead of the two old resource summaries. Dispatch puts the work board above Owner tools and collapses TV configuration. Explicit ticket creation routes keep their original controls. The unit card retains direct Ping/Scan and calls the connection editor Advanced settings. No scan runs automatically. Unverified camera reasons are available under a plain-language disclosure.

Verified IT phone users can explicitly select the same Fleet map and troubleshooting view as desktop. Handoffs stay the default. An open transfer form prevents switching; transfer readiness, custody checks, recipient checks, and signatures remain enforced. Preview and unauthorized accounts stay blocked. The toggle never submits transfers.

This release changes frontend presentation and navigation only. It does not enable vendor/Sheet writeback, alter equipment placement, probe cameras, or change provider polling and permissions. Counts are source-driven; fixture baselines are not production constants.
